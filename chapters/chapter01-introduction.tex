\section{Background of the Practical Training}
Practical training is an essential part of my studies at Arusha Technical College. It helps me apply the classroom knowledge I gained during my Higher Diploma in Computer Science to a real-world professional environment. For my training, I was placed in the Software Engineering department at Vodacom Tanzania for a period of eight weeks. During this time, I worked on "Argus" (also referred to as "Secure Signal"), a mobile-first platform designed to detect and block fraudulent SMS messages using machine learning.

\section{Problem Statement}
In Tanzania and across the globe, mobile phone users frequently receive deceptive SMS messages. These messages often mimic trusted organizations like banks or telecommunication companies, promising fake lottery prizes, asking for urgent money transfers, or trying to steal user credentials. For ordinary users, it is very difficult to manually identify which messages are legitimate and which are scams. 

The goal of this project is to solve this problem by creating a mobile application that automatically scans incoming SMS messages and warns the user in real-time. By building a local rule-based filter combined with a powerful server-side artificial intelligence model (BERT), we can screen these messages and keep users safe from financial loss and data theft.

\section{Motivation for Selecting the Project}
I selected this project because digital fraud is a growing challenge that affects many lives in our society. Working on Argus gave me a unique opportunity to learn and connect multiple modern technologies. I wanted to gain hands-on experience in:
\begin{itemize}
  \item Mobile application development using Flutter.
  \item Creating robust backend APIs with Spring Boot.
  \item Building interactive user interfaces using React.
  \item Implementing natural language processing (NLP) models in Python.
\end{itemize}
This project represents a perfect bridge between my academic studies in computer science and the skills needed in the modern software industry.

\section{Objectives of the Project}
The main aim of my training project was to study, develop, and integrate the different parts of the Argus SMS fraud detection system to make it fully functional and secure.

To achieve this main aim, I focused on the following specific objectives:
\begin{enumerate}
  \item To understand the software architecture of the monorepo, mapping how the mobile app, backend, web dashboard, and machine learning service communicate.
  \item To implement and configure a local rule-based screening engine in Flutter for immediate offline alerts on Android devices.
  \item To connect the Flutter app and Spring Boot backend to the FastAPI BERT service for advanced server-side text classification.
  \item To study the data schema and implement secure user registration, login, and scan history tracking.
  \item To explore the admin web dashboard and identify the steps required to link its user interface with real backend statistics.
\end{enumerate}

\section{Scope of the Work}
My work during the eight weeks was focused on the components contained in the Argus monorepo:
\begin{itemize}
  \item The mobile app in the \texttt{frontend/} directory, including Android SMS reading permissions, local notifications, and user interfaces.
  \item The Spring Boot API in the \texttt{backend/} folder, managing security with JSON Web Tokens (JWT) and PostgreSQL database storage.
  \item The Python machine learning service in the root directory, loading a pre-trained BERT classifier on FastAPI.
  \item The React administrative client in the \texttt{web-client/} folder.
\end{itemize}
My focus was on understanding how these components exchange data, and identifying and resolving integration issues to make the system more cohesive.

\section{Significance of the Project}
This project is highly significant for several reasons:
\begin{itemize}
  \item \textbf{User Protection:} It provides a real-time warning system on users' mobile phones, helping to prevent scams and financial fraud.
  \item \textbf{Heuristic and AI Integration:} It combines fast, offline-capable local keyword rules with an advanced machine learning model on the cloud, balancing speed and accuracy.
  \item \textbf{Administrative Oversight:} It enables telecommunication administrators to view fraud trends and block malicious senders through a centralized web portal.
\end{itemize}

\section{Limitations of the Work}
While the project provides a strong foundation, there were several limitations during my work:
\begin{itemize}
  \item Android has strict security policies for SMS reading, which requires specific runtime permissions and makes the application platform-specific.
  \item The machine learning model requires significant computing power, so the AI classification must be done on the server rather than locally on the phone.
  \item Some parts of the web administrator dashboard and mobile feedback routes are still prototypes that use simulated data and require full backend integration.
  \item I did not have access to a large, real-world Tanzanian SMS dataset to retrain or fine-tune the BERT model, meaning we rely on the pre-saved weights.
\end{itemize}
