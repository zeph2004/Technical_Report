\section{Project Summary}
My 8-week practical training at Vodacom Tanzania was a highly successful and educational experience. During this time, I worked on the Argus SMS fraud detection platform. This system is designed to protect mobile users from deceptive and malicious messages by using a smart combination of fast, local keyword rules and a powerful server-side artificial intelligence model (BERT). Working on a monorepo that spans mobile, web, backend API, and machine learning components allowed me to understand the end-to-end integration of a modern software system.

\section{Summary of Implementation}
By the end of my training, we had a fully working prototype of the Argus ecosystem:
\begin{itemize}
  \item The \textbf{Flutter Mobile App} successfully intercepts incoming Android SMS messages, performs local keyword checks, runs local notifications, and logs scans in device memory.
  \item The \textbf{Spring Boot Backend} secures API requests with JWT, hashes user passwords with BCrypt, coordinates scan requests, and manages the PostgreSQL database.
  \item The \textbf{FastAPI Python Service} successfully loads the pre-saved BERT model and returns context-aware predictions.
  \item The \textbf{React Web Dashboard} provides a highly interactive admin panel, which serves as a great blueprint for security officers to review fraud events and block spam numbers.
\end{itemize}

\section{Key Contributions and Findings}
My primary contribution during this training was analyzing, testing, and documenting the connection boundaries of the Argus platform. I identified slight inconsistencies in the authentication contracts and mapped out exactly how to resolve them. 

My key findings include:
\begin{itemize}
  \item Combining local heuristics and server-side BERT is an excellent architecture for mobile security, offering both high speed and deep understanding.
  \textbf{Swahili support is vital} for Tanzanian fraud detection, as scammers frequently write deceptive text using local slangs and transfer terms.
  \item Containerization with Docker Compose is a game-changer for developer productivity, allowing easy deployment of databases and Python services.
\end{itemize}

\section{Recommendations for Future Work}
Based on my observations during my training, I recommend the following priorities for the next stage of development:
\begin{enumerate}
  \item \textbf{Clean up the monorepo:} Delete the legacy root \texttt{lib/} directory and make \texttt{frontend/} the single canonical Flutter package to avoid developer confusion.
  \item \textbf{Unify authentication paths:} Update the mobile and web login scripts to use the exact same Spring Boot security controller and token exchange flows.
  \item \textbf{Connect the Web Admin API:} Replace the React client's mock arrays with active HTTP fetch requests pointing to the existing \texttt{/api/admin/**} endpoints.
  \item \textbf{Durable OTP and Blocklists:} Move the one-time passwords and blocked numbers from local files/memory to shared databases (like PostgreSQL or Redis) to make them resilient across server restarts.
\end{enumerate}

\section{Final Conclusion}
In conclusion, my practical training at Vodacom Tanzania was an invaluable milestone in my academic and professional journey. It provided me with rich, hands-on software engineering skills and allowed me to contribute to a meaningful project that tackles real-world digital fraud. 

The Argus platform is a strong, well-designed foundation that can protect mobile users and give administrators powerful security tools. By aligning the remaining integration gaps and connecting the admin dashboard to the live API, Argus will be fully prepared for a successful, production-ready rollout to safeguard our digital community.
