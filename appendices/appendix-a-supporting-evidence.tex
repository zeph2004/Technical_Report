\section{English Threat Keywords}
The local rule-based engine in the Flutter mobile application uses case-insensitive pattern matching to instantly flag common scam indicators. The primary English keywords and phrases that I analyzed and configured include:
\begin{itemize}
  \item \textbf{Lottery and Reward Prompts:} \texttt{win}, \texttt{prize}, \texttt{won}, \texttt{lottery}, \texttt{congratulations}, \texttt{voucher}, \texttt{gift card}, \texttt{lucky draw}, \texttt{reward code}.
  \item \textbf{Urgency and Security Alerts:} \texttt{suspended}, \texttt{blocked}, \texttt{unauthorized access}, \texttt{security alert}, \texttt{verify account}, \texttt{immediate action required}.
  \item \textbf{Financial Prompts:} \texttt{send money}, \texttt{payment notice}, \texttt{overdue invoice}, \texttt{credentials transfer}, \texttt{deposit requested}.
\end{itemize}

\section{Swahili Threat Keywords}
Because scammers in East Africa frequently target mobile money users in their local language, a robust Swahili keyword filter is vital for protecting Tanzanian customers. Some of the key Swahili scam patterns I analyzed and included are:
\begin{itemize}
  \item \textbf{Fake Money Transfer Requests:} \texttt{utatuma kwa namba hii} (you will send to this number), \texttt{lipia namba} (pay to this number), \texttt{tuma kwenye namba} (send to the number), \texttt{pesa imeshatumwa} (money has already been sent).
  \item \textbf{Verification Prompts:} \texttt{hakikisha jina} (make sure to confirm the name), \texttt{thibitisha muamala} (confirm the transaction), \texttt{sajili line} (register SIM card).
  \item \textbf{Banking Scams:} \texttt{akaunti imefungwa} (your account is closed), \texttt{bofya kiungo} (click the link to verify), \texttt{taarifa za siri} (secret credential details).
\end{itemize}
These keywords provide immediate, lightweight offline screening directly on the device, ensuring the user is always protected.
