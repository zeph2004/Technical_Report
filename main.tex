\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
During my eight-week Practical Training at Vodacom Tanzania, I worked on developing and documenting "Argus," a system designed to protect mobile users from SMS-based fraud. The project involved building a multi-part platform that includes a Flutter mobile app, a Spring Boot backend, a React web dashboard, and a machine learning service using FastAPI.

The mobile app I worked on can automatically detect suspicious SMS messages on Android devices using both local rules and a powerful AI model (BERT) hosted on the backend. My work focused on integrating these different parts, ensuring that users receive real-time alerts for scams while allowing administrators to monitor fraud trends through the web dashboard. This report details the design and implementation of Argus, the testing I conducted to verify its performance, and the valuable lessons I learned about software engineering and cybersecurity in a real-world setting. I conclude with recommendations for further improving the system's accuracy and security.
